# Etkileşimli Ders Deneyimi Panosu

## Proje Hakkında

Etkileşimli Ders Deneyimi Panosu, öğrencilerin ders haftalarını, öğrenme hedeflerini, görevlerini ve genel ilerlemelerini tek bir web arayüzünden takip etmelerini sağlayan bir uygulamadır.

Projenin temel amacı, öğrencilerin öğrenme süreçlerini daha düzenli, anlaşılır ve etkileşimli hâle getirmektir.

## Temel Özellikler

- Haftalık ders ve öğrenme kartları
- Görev ve mini etkinlik listesi
- Görev durumlarını yönetme
- Görevleri filtreleme ve arama
- Genel ilerleme göstergesi
- Mobil cihazlara uyumlu responsive tasarım
- Karanlık ve aydınlık tema
- Verilerin tarayıcıda saklanması
- Klavye ile kullanılabilir kontroller ve erişilebilir arayüz

## Kullanılacak Teknolojiler

- HTML
- CSS
- JavaScript
- localStorage
- JSON (gerektiğinde veri düzenleme için)

## Proje Kapsamı

Uygulama tarayıcı tabanlı geliştirilecektir. Temel sürümde zorunlu bir veritabanı veya karmaşık bir backend bulunmayacaktır. Öncelik, kullanıcı deneyimi, çalışan işlevler, responsive tasarım ve temiz istemci tarafı kodudur.

## Geliştirme Süreci

Proje dört haftalık bir süreçte geliştirilecektir:

1. İhtiyaç analizi ve görev paylaşımı
2. Arayüz tasarımı ve temel yapı
3. Özelliklerin geliştirilmesi ve test edilmesi
4. Son testler, dokümantasyon ve sunum

## Teslim İçeriği

- Çalışan web uygulaması
- Kaynak kod ve GitHub commit geçmişi
- Proje raporu

- Kullanıcı dokümantasyonu
- Sunum ve demo
