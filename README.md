# EduTrack – Etkileşimli Ders Deneyimi Panosu

## Proje Hakkında
EduTrack, öğrencilerin haftalık ders içeriklerini, görevlerini ve ilerleme durumlarını takip edebilmelerini sağlayan etkileşimli bir web uygulamasıdır.

## Kullanılan Teknolojiler
- HTML5
- CSS3
- Vanilla JavaScript
- localStorage
- JSON

## Temel Özellikler
- Haftalık ders kartları
- Görev listesi ve görev durumunu değiştirme
- Görev arama
- Durum ve hafta filtreleme
- Genel ilerleme göstergesi
- Karanlık ve aydınlık tema
- Responsive tasarım
- localStorage ile verilerin saklanması

## Proje Dosya Yapısı
- `index.html`: Ana sayfa
- `css/style.css`: Tasarım ve stiller
- `js/app.js`: Uygulamanın ana işlevleri
- `js/courses.js`: Ders verileri
- `js/tasks.js`: Görev verileri
- `js/storage.js`: Veri saklama işlemleri
- `assets/images/`: Görseller

## Nasıl Çalıştırılır?
1. Proje klasörünü bilgisayara indirin veya açın.
2. `index.html` dosyasını VS Code ile açın.
3. Live Server eklentisi üzerinden uygulamayı çalıştırın.

## Geliştirme Durumu
İkinci hafta kapsamında temel arayüz, görev yönetimi, filtreleme, arama, tema değiştirme ve veri saklama özellikleri geliştirilmiş ve tarayıcıda test edilmiştir.
